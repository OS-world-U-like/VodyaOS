# VodyaOS

## 追逐梦想

VodyaOS 是一个以 Unix 血脉为底色的开源系统项目，致力于回溯经典 Unix 设计理念，并在现代开发实践中重建一套可理解、可扩展、可研究的操作系统体验。

我们相信：
- 代码不是冰冷的历史，而是通往未来的桥梁
- 从 Unix V7 开始，追逐梦想，重新理解系统的本质
- 让经典与现代在同一套工程中对话

### 关联的 Unix V7 源码

这个仓库将 Unix V7 作为参考与基础来源，保留子模块入口，便于本地拉取和研究：
- 上游源代码: https://github.com/gerlevodka/unixv7
- 本地目录: `unixv7`
